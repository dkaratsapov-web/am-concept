# A&M Concept — лендинг клуба женского фитнеса

Воссоздание дизайна из Figma: одностраничный лендинг фитнес-клуба
«A&M Concept» (Тверь). Тёмная оливковая тема, кремовая типографика,
дисплейный шрифт в стиле Bebas Neue / Oswald.

## Запуск

Это статический сайт без сборки — просто откройте `index.html`
в браузере. Либо поднимите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура

```
index.html   — разметка всех секций
styles.css   — оформление, палитра, адаптив
script.js    — маска телефона, форма, появление секций при скролле
```

## Секции

1. Шапка с навигацией и логотипом
2. Hero — «A&M Concept — Фитнес, который чувствует вас»
3. О студии
4. Пространство — «Центр женской поддержки»
5. Комьюнити
6. Направления (6 карточек)
7. Услуги — тренировки и массаж
8. Тренеры (4 карточки)
9. Акции + форма «Карта клуба»
10. Контакты + карта
11. Подвал с крупным логотипом

## Заметки по реализации

- **Шрифты** подключены из Google Fonts: `Oswald` (дисплейный, с
  поддержкой кириллицы — замена `Bebas Neue Cyrillic` из макета) и
  `Manrope` (основной текст).
- **Фотографии** заменены на стилизованные градиентные плейсхолдеры,
  поскольку исходные изображения из Figma недоступны для выгрузки.
  Чтобы подставить реальные фото — замените фон у элементов `.photo`,
  `.hero__photo`, `.about__photo` и т.д.
- Декоративная векторная иллюстрация из hero-блока заменена
  композицией фото-карточек и мягкими «свечениями».
